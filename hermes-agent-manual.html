什么是 Hermes Agent

"An agent that grows with you" — 与你共同成长的 Agent

核心定位：最大的特点是可以自进化。

Hermes Agent 部署在你的服务器上，连接你的消息账号，它就成为你的持久个人智能体——学习你的项目、自动构建技能、随时随地触达你。不是聊天机器人，不是代码补全工具，而是一个住在你机器上、每天都在变聪明的智能体。

01

核心创新：内置自学习循环

Hermes Agent 不是简单地调用 LLM，而是通过内置的学习循环不断优化自身：

🔄

自动从交互中生成 Skill（技能）

每累计 15 次工具循环，自动在后台启动 Skill Review，将有价值的操作固化为可复用技能。

📈

在使用中持续迭代技能

发现可更新的现有技能时自动补充新经验；发现值得新建的技能时创建新技能文件。

🧠

主动持久化知识和用户偏好

通过 MEMORY.md 和 USER.md 跨会话持久化，记住你的项目、环境和习惯。

🔍

跨会话构建对用户的深度理解

所有历史对话存储在本地 SQLite，支持 FTS5 全文搜索 + LLM 摘要，几周前的内容也能找到。

右键点击开始菜单 → 选择「Windows PowerShell（管理员）」或「终端（管理员）」。

执行 WSL 安装命令

在 PowerShell 中输入以下命令，然后按回车：

重启计算机

官方文档说重启一次即可，实际上可能需要 2–3 次重启。注意：是重启，不是关机再开机。

POWERSHELL

05

安装 Hermes Agent

无需任何前置依赖，在 WSL2 的 Ubuntu 终端中一键自动安装所有组件：

BASH · WSL2/Ubuntu 
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
⚠️
特别声明：
· 安装时无需翻墙，非要翻墙请自重（如果实在下载不动，那你翻吧）
· 程序员注意！请将 pip 镜像和 npm 镜像还原（别问，问就是坑，大坑，天坑）

安装流程说明

等待自动安装依赖

这部分安装时间有点长，保持网络畅通，耐心等待... 安装程序会自动检测并安装所有缺失组件。

输入 WSL 密码

安装依赖完成后，输入 WSL 的用户密码即可进入下一步。

选择模型

选择你熟悉的或有额度的模型，推荐选择 DeepSeek。如果选错了，事后执行 hermes model 可重新选择。

接入应用（可跳过）

首次安装时可以先跳过应用接入，后续通过 hermes gateway setup 单独接入。

启动 Hermes

到这里就成功了！执行 hermes 命令开始使用，或执行 hermes gateway 启动消息网关。

✅
加 -x 参数可以看到每一步的执行过程，便于排查问题：
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash -x
06

接入应用：QQ

执行以下命令启动应用接入向导：

BASH 
hermes gateway setup

在平台列表中选择 QQ Bot

从列表中找到并选择「QQ Bot (configured)」选项。

选择扫码接入（推荐）

选择「Scan QR code to add bot automatically (recommended)」，扫码接入就行，很简单哦～

配置消息授权方式

选择 DM 配对审批（推荐）/ 允许所有直接消息 / 仅允许已列明的用户 OpenIDs。

后续全部 Yes，然后重启网关

消息即可正常接收。

07

接入应用：微信

微信的接入与 QQ 类似，但需要额外进行设备配对。

授权配置选项

使用 DM 配对审批（推荐） 允许所有直接消息 仅允许已列明的用户 OpenIDs 禁用私信

群聊处理方式

禁用群聊（推荐） 允许所有群聊 只允许列出的群聊 ID
🔗
微信设备配对：与 QQ 不同，微信需要进行设备配对。
向 Bot 发消息后，它会返回一个配对码，在 WSL 中执行以下命令完成配对：
hermes pairing approve weixin ZV5J582F（ZV5J582F 为示例配对码）
08

接入应用：飞书

飞书接入方式与微信类似，同样需要配对，但流程更加简洁。

选择 Feishu / Lark

在平台列表中选择「Feishu / Lark」，然后选择「Scan QR code to create a new bot automatically (recommended)」。

配置私信授权

推荐选择「Use DM pairing approval」。

配置群聊处理

推荐选择「Respond only when @mentioned in groups」，禁用群聊也可以。

完成配对

与接入微信一样，需要配对：hermes pairing approve feishu [配对码]

💡
支持接入的平台还包括：Telegram、Discord、Slack、Matrix、WhatsApp、Signal、Email、SMS（Twilio）、DingTalk、WeCom（企业微信）、BlueBubbles（iMessage）等。

个性化定制：SOUL.md

Hermes Agent 的个性是完全可定制的。SOUL.md 是主要身份——它是系统提示词的第一部分，定义了 Agent 是谁。

文件位置
~/.hermes/SOUL.md
系统优先级
系统提示词中占据位置 #1
自动生成
首次启动时自动创建默认版本，现有文件永远不会被覆盖

SOUL.md 应该放什么内容

✅

适合放入

语调 · 沟通风格 · 直接程度 · 默认交互风格 · 风格上要避免什么 · 如何处理不确定性

❌

不适合放入

一次性的项目指令 · 文件路径 · 仓库规范 · 临时工作流细节

参考配置示例

SOUL.md · YAML + MARKDOWN 
---
name: iwen
version: 1.0
---

# 思考模式
- 先验证后回答：不确定的 API、配置、路径，先查工具确认，不靠猜测
- 先计划后执行：3步以上的任务，先列方案标风险，确认再动手
- 交付即验证：做完一件事，主动给出「怎么检查它是否生效」

# 自我约束
- 不确定时直接说「我不确定」
- 高危操作（删数据、重启、覆盖）必须预警

# 输出纪律
- 结论先行，代码/命令为主，少废话
💡
最佳实践：先和 Hermes 正常使用 1-2 天，展现你的工作风格和偏好，然后问它：「灵魂定义（SOUL.md）你有没有推荐的配置，基于我们的对话风格来建议？」它会读取历史会话，生成贴合你习惯的配置，再让它写入 ~/.hermes/SOUL.md。

工具是扩展 Agent 能力的函数，被组织成逻辑上的工具集（Toolsets），可以按平台启用或禁用。Hermes 内置了广泛的工具注册表。

类别示例工具描述
网络 web_search web_extract 搜索网络并提取页面内容
终端与文件 terminal read_file patch 执行命令并操作文件
浏览器 browser_navigate browser_vision 支持文本与视觉的交互式浏览器自动化
媒体 vision_analyze image_generate text_to_speech 多模态分析与生成
Agent 编排 todo clarify delegate_task 规划、澄清、代码执行与子 Agent 委托
记忆与召回 memory session_search 持久化记忆与会话搜索
自动化与交付 cronjob send_message 定时任务与出站消息传递

Skills 技能系统

技能是按需加载的知识文档，Agent 在需要时可将其载入。它们遵循渐进披露模式，最小化 token 使用量。

技能目录
~/.hermes/skills/（单一事实来源）
自动沉淀
每累计 15 次工具循环，后台自动启动 Skill Review

查看与管理技能

BASH 
# 查看技能列表
hermes skills list

# 浏览所有 hub skills（官方优先）
hermes skills browse

# 搜索技能
hermes skills search kubernetes

# 安装前预览
hermes skills inspect openai/skills/k8s

# 安全扫描后安装
hermes skills install openai/skills/k8s

自动技能沉淀的三种结果

🔄

发现可更新的现有技能

自动更新补充新经验。

✨

发现值得新建的技能

创建新技能文件，固化为可复用的操作流程。

🔇

没有值得保存的内容

输出 Nothing to save. 结束。整个过程在后台线程运行，不阻塞当前对话。

12

持久记忆系统

Hermes Agent 拥有受限且经过精选的记忆，可以跨会话持久存在，记住你的偏好、项目、环境以及它所学到的知识。

文件用途字符限制
MEMORY.md Agent 的个人笔记——环境事实、约定、学到的知识 2,200 字符（约 800 tokens）
USER.md 用户画像——你的偏好、沟通风格、期望 1,375 字符（约 500 tokens）

两个文件都存储在 ~/.hermes/memories/ 中，在会话开始时作为冻结快照注入到系统提示词中。

记忆操作命令

BASH 
# 查看历史会话
hermes sessions list

# 配置外部记忆 Provider（Honcho、mem0 等）
hermes memory setup

什么该存，什么不该存

✅

主动存储

用户偏好 · 环境事实 · 修正记录 · 项目约定 · 已完成的工作 · 明确的要求

🚫

跳过不存

琐碎信息 · 容易重新发现的事实 · 原始数据转储 · 会话特定的临时信息

💡
温馨提示：字符限制是为了保持记忆的聚焦。当记忆存满时，Agent 会合并或替换条目，以为新信息腾出空间。

MCP 扩展 AI 工具能力

MCP（Model Context Protocol）是由 Anthropic 提出的开放协议，定义了 AI Agent 与外部工具之间的标准通信接口。简单说：MCP 让 AI 可以「使用工具」，就像人类使用各种软件一样。

💻

Stdio 服务器（本地）

本地运行的子进程，通过 stdin/stdout 通信。低延迟，适合访问本地资源。

🌐

HTTP 服务器（远程）

连接到远程端点，适合组织内部 API 或托管服务，不在本地启动子进程。

配置 GitHub MCP 服务器（示例）

编辑配置文件

编辑 ~/.hermes/config.yaml，添加 mcp_servers 配置段。

获取 GitHub Personal Access Token

GitHub 头像 → Settings → Developer settings → Personal access tokens → Generate new token，可全部勾选权限。

验证配置

执行 hermes tools list 查看所有可用工具，包括 MCP 提供的。

YAML · ~/.hermes/config.yaml 
mcp_servers:
  github:
    command: "npx"
    args: ["-y", "@modelcontextprotocol/server-github"]
    env:
      GITHUB_PERSONAL_ACCESS_TOKEN: "ghp_xxx..."

常用 MCP 服务器推荐

MCP 服务器功能
server-githubGitHub 仓库操作
server-postgresPostgreSQL 查询
server-sqliteSQLite 操作
server-filesystem文件系统操作
server-brave-searchBrave 搜索
playwright-mcp浏览器自动化

定时任务（Cron）

使用自然语言或 cron 表达式安排任务自动运行。Hermes 通过一个统一的 cronjob 工具来管理 cron。

调度格式

格式类型示例含义
相对延迟（一次性）30m / 2h / 1d30 分钟后运行一次
间隔（重复）every 30m / every 2h每 30 分钟运行一次
Cron 表达式0 9 * * 1-5工作日上午 9:00

管理定时任务

BASH · 聊天命令 
# 在聊天中添加定时任务
/cron add 30m "提醒我检查构建"
/cron add "every 2h" "检查服务器状态"
/cron add 'every 1h' '看一次天气预报' --skill taiyuan-weather

# 管理任务
/cron list                  # 列出所有任务
/cron pause <job_id>        # 暂停任务
/cron resume <job_id>       # 恢复任务
/cron remove <job_id>       # 删除任务
💡
Cron 执行由网关守护进程处理。网关每 60 秒触发一次调度器，在独立的 Agent 会话中运行所有到期的任务。也可以通过自然对话触发：「每天上午 9 点提醒我喝水」

Web 仪表板

Web 仪表板是一个基于浏览器的用户界面，用于管理你的 Hermes Agent 安装。无需编辑 YAML 文件或运行 CLI 命令，通过简洁的 Web 界面即可配置设置、管理 API 密钥和监控会话。

BASH 
# 启动仪表板（默认打开 http://127.0.0.1:9119）
hermes dashboard

# 自定义端口
hermes dashboard --port 8080

# 绑定到所有网络接口（共享网络请谨慎）
hermes dashboard --host 0.0.0.0

# 启动时不自动打开浏览器
hermes dashboard --no-open
🔒
仪表板完全在你的机器上运行——没有任何数据会离开本地主机，访问地址为 http://127.0.0.1:9119。

最佳实践：Hermes 八大亮点

#亮点说明
① 智能授权 自动识别高危指令，清晰说明意图再请求授权
② 会话感知 通过 Session 阅读机制感知历史对话，可据此生成个性化 SOUL.md
③ 多模型路由 Auxiliary 支持为 8 类任务分配独立模型，省钱且高效
④ 配置解耦 密钥与配置分离，YAML 格式友好，修改直观
⑤ 工具透明 IM 界面清晰打印每次 tool 调用过程，执行过程完全可见
⑥ 多 Profile 多实例配置简单，一句话完成，轻松实现沙箱 / 主力分离
⑦ 自动技能沉淀 将有价值操作自动总结为可复用技能，避免重复踩坑
⑧ 消息不丢失 20 个退出触发点，增量写入，无论正常 / 异常退出都不丢消息

实战案例：应用 Agent 完成复杂任务

帮我上网看看最近比较火的 Agent 有哪些？然后总结成文档，注意文档中要附上和这个技术相关的重要连接，例如：官网网站，重要博客，GitHub 等。接着，帮我生成一个静态页面，专门用来展示这个文档。网页要有科技感，完成后，告诉我资源存放在哪里，帮我在本地启动这个前端页面。

→ Hermes 会自动搜索、整理文档、生成科技感页面并启动本地服务器，全程自动完成。
